# Versiones exactas, a proposito.
#
# Un rango abierto (>=, ~=) significa que tu maquina, la de tu companero y el
# servidor pueden instalar versiones distintas. Cuando eso pasa con scikit-learn,
# el modelo que exportaste deja de cargar y el error no dice por que.
#
# Esto no es burocracia: es la diferencia entre "funciona en mi maquina" y
# "funciona".
#
# Estas versiones tienen que poder instalarse en DOS entornos:
#
#   · Python 3.12, que es el que trae Ubuntu 24.04 en tu instancia
#   · Python 3.13, que es el que usa Google Colab, donde entrenas el modelo
#
# Por eso numpy es 2.x y pandas 2.2.3: las versiones anteriores no tienen
# paquetes precompilados para 3.13, y pip intenta compilarlas desde fuente y
# falla. Si alguna vez cambias una version, comprueba las dos.

Flask==3.0.3
Flask-Cors==4.0.1
pandas==2.2.3
numpy==2.1.3

# Se usan a partir de la sesion 2, pero se fijan desde ahora: la version de
# scikit-learn con la que entrenas tiene que ser la misma con la que sirves.
scikit-learn==1.5.2
joblib==1.4.2

# Servidor de produccion, se usa dentro del contenedor en la sesion 4.
# El servidor de desarrollo de Flask no esta hecho para produccion.
gunicorn==22.0.0

# --- Agregado para el reto (Spaceship Titanic) -----------------------------
#
# El artefacto de clasificacion lleva un XGBClassifier DENTRO del pipeline.

# el servicio truena al arrancar con "No module named 'xgboost'" y el error no
# menciona al modelo por ningun lado.
#
# OJO: este archivo es [DEL CURSO] en setup/archivos-del-curso.txt, asi que
# './setup/run actualizar N' lo sobreescribe con la version del curso y borra
# esta linea. Si despues de actualizar el servicio no arranca, es esto.
