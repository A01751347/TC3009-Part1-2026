# Material original del curso

Lo que venía en el template de TC3009 Parte 1, archivado **sin modificar** salvo las rutas
relativas, que se ajustaron al bajar un nivel de carpeta.

Este proyecto se re-apuntó del modelo de precios de vivienda (Ames, Iowa) al clasificador de
Spaceship Titanic, así que los documentos de arriba describen un dataset que ya no es el de
este repositorio. Se conservan porque explican **por qué** el template está hecho como está,
y esa parte no cambió.

| [api-contrato-casas.md](api-contrato-casas.md) | El contrato original. El vigente es [../api-contrato.md](../api-contrato.md) |
| [s1-guia.md](s1-guia.md) | Sesión 1 — la máquina y el contrato |
| [s2-guia.md](s2-guia.md) | Sesión 2 — el modelo cruza la frontera |
| [s3-guia.md](s3-guia.md) | Sesión 3 — el producto (frontend) |
| [s4-guia.md](s4-guia.md) | Sesión 4 — memoria, palabras y un origen de verdad |
